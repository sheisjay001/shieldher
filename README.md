# 500 Level Project: Safe Digital Space for Women

## Overview
This project aims to bridge the gender gap in cybersecurity and provide a safe social platform for women. It combines education with a secure social environment.

## Project 1: CyberSecure Women (Education Platform)
**Goal:** A learning platform strictly for women to master cybersecurity.
*   **Features:**
    *   Women-only registration & authentication.
    *   Video tutorials & article-based lessons.
    *   Hands-on labs (password cracking, phishing simulations).
    *   Sandbox environments (TryHackMe/OverTheWire integration).
    *   Leaderboards & certification badges.
    *   Discussion forums.

## Project 2: ShieldHer (Social Platform)
**Goal:** A safe social media platform to detect & prevent online harassment.
*   **Core Features:**
    *   **Secure Messaging:** Direct Messages (DMs) are automatically deleted 5 minutes after the receiver reads them to prevent data theft in case of account compromise.
    *   **AI-Powered Safety:**
        *   Content moderation to flag offensive text/images.
        *   NLP-based harassment detection in real-time.
    *   **Verification:** Women-only access via strict verification (e.g., selfie ID, invite system).
    *   **Community:** Connect, share posts, and report abuse.
    *   **User Safety:** User behavior scoring, blacklisting, and manual report systems.

## Proposed Tech Stack
*   **Frontend:** React.js or Next.js
*   **Backend:** Node.js (Express) or Python (Django/Flask)
*   **ML/NLP:** Python (TensorFlow, scikit-learn, spaCy)
*   **Database:** MongoDB or PostgreSQL
*   **Authentication:** Firebase Auth + Gender Filter
